## Screenshots (what to capture)

Required: 5-8 screenshots per device size, 9:16 portrait. Order them to tell a story:

1. **Gameplay hero shot** — Player ship mid-action with beam firing and enemies exploding. Should be the best-looking combat frame in the game.
2. **Mobile controls shown** — Gameplay frame with the mobile controls HUD visible (torpedo/weapon/pause buttons). Signals "designed for phone."
3. **Boss encounter** — A boss filling the screen with bullet patterns. Shows scale.
4. **Starbase shop** — Shopkeeper dialog + item cards. Signals depth / progression.
5. **Cutscene still** — The grandmother hologram shot (`cutscene_04_act4_02_grandmother_hologram`) with caption overlay. Signals story.
6. **Weapon switch / big beam mid-fire** — Shows the power ceiling.
7. **Final boss / ending shot** — "there's a real payoff" signal.
8. *(Optional)* Progression / upgrade screen — if you want to show the 20-tier ladder.

Every screenshot should be captured at 1284×2778 (iPhone 14 Pro Max) minimum and rescaled down for smaller sizes — Apple accepts a single 6.7" set for all device sizes these days.
